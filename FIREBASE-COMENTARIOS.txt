PASO 3 — Firestore
------------------
Build → Firestore Database → Crear base de datos
Modo: producción → región europe-west (Europa)

Reglas → pegar (sustituye TU_CORREO@gmail.com por tu correo real):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isCommentsAdmin() {
      return request.auth != null
        && request.auth.token.email == 'mbardisa@gmail.com';
    }
    match /comments/{postId}/messages/{messageId} {
      function isReply() {
        return 'parentId' in request.resource.data
          && request.resource.data.parentId is string
          && request.resource.data.parentId.size() > 0;
      }
      allow read: if true;
      allow create: if request.auth != null
        && request.resource.data.uid == request.auth.uid
        && request.resource.data.text is string
        && request.resource.data.text.size() > 0
        && request.resource.data.text.size() <= 500
        && (!('authorEmail' in request.resource.data)
          || (request.resource.data.authorEmail is string
            && request.resource.data.authorEmail.size() <= 254
            && request.resource.data.authorEmail == request.auth.token.email))
        && (!isReply() || isCommentsAdmin());
      allow update, delete: if request.auth != null
        && (resource.data.uid == request.auth.uid || isCommentsAdmin());
    }
    match /dojo_subscribers/{subscriberId} {
      allow create: if request.auth != null
        && request.resource.data.email == request.auth.token.email
        && request.resource.data.name is string
        && request.resource.data.name.size() > 0
        && request.resource.data.name.size() <= 80
        && request.resource.data.email is string
        && request.resource.data.email.size() > 5
        && request.resource.data.email.size() <= 254
        && request.resource.data.marketingConsent is bool
        && request.resource.data.marketingConsent == true;
      allow read: if isCommentsAdmin()
        || (request.auth != null && resource.data.email == request.auth.token.email);
      allow update: if isCommentsAdmin()
        || (request.auth != null
          && resource.data.email == request.auth.token.email
          && request.resource.data.active == false
          && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['active', 'unsubscribedAt']))
        || (request.auth != null
          && resource.data.email == request.auth.token.email
          && request.resource.data.active == true
          && request.resource.data.email == request.auth.token.email
          && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['active', 'name', 'marketingConsent', 'consentAt']));
      allow delete: if isCommentsAdmin();
    }
  }
}

MODERAR COMENTARIOS (borrar)
---------------------------
1. En comments-config.js pon tu correo en adminEmail (el mismo de Google/Firebase).
2. En Firestore Reglas usa el mismo correo en isCommentsAdmin().
3. En la web: abre una entrada → Comentarios → entra con tu cuenta (mbardisa@gmail.com).
4. Verás "Eliminar" y "Responder" en cada comentario.

RESPONDER COMENTARIOS (solo admin)
----------------------------------
Entra con tu correo admin → "Responder" debajo del comentario → escribe y publica.
La respuesta aparece indentada justo debajo. Actualiza Reglas (bloque isReply arriba).

AVISO POR CORREO AL RESPONDER
-----------------------------
Guía: MAKE-COMMENT-REPLY.txt
1. Crea escenario Make (webhook → filtro token → Gmail).
2. Pega la URL del webhook en comments-config.js → replyNotifyWebhook.
3. Sube la web (git push). Comentarios nuevos guardan authorEmail para el aviso.
4. Comentarios antiguos sin authorEmail: respuesta OK, pero sin email al lector.

Alternativa sin código: Firebase → Firestore → Datos → comments → borrar a mano.

Si ves: auth/api-key-not-valid
--------------------------------
A) Vuelve a copiar la apiKey desde Firebase (no de un chat ni captura antigua).
B) Google Cloud → APIs y servicios → Credenciales → "Browser key (auto created by Google Service)"
   - Restricciones de aplicación: "Ninguno" (para probar) O referentes HTTP:
     https://elmanuscritozen.com/*
     https://www.elmanuscritozen.com/*
     https://el-manuscrit-zen.firebaseapp.com/*
   - Restricciones de API: "No restringir clave" O incluir "Identity Toolkit API"
C) Google Cloud → APIs y servicios → Biblioteca → busca "Identity Toolkit API" → debe estar HABILITADA
D) Guarda, espera 2 min, Ctrl+F5 en la web

PASO 7 — Si "Continuar con Google" falla
-----------------------------------------
Mensaje genérico "No se pudo completar" → casi siempre es configuración de Google OAuth.

A) Pantalla de consentimiento OAuth (LO MÁS FRECUENTE)
   1. Firebase → Project settings (engranaje) → "Your project" → enlace a Google Cloud
   2. Menú → APIs y servicios → Pantalla de consentimiento de OAuth
   3. Si el estado es "Prueba" / "Testing":
      - Añade tu Gmail (mbardisa@gmail.com) en "Usuarios de prueba", O
      - Pulsa "Publicar aplicación" (External) — para un blog personal suele bastar
   4. Sin esto, Google bloquea el acceso aunque Firebase esté bien.

B) Google habilitado en Firebase
   Authentication → Sign-in method → Google → Activado + correo de asistencia guardado

C) Dominios autorizados
   Authentication → Settings → Authorized domains:
   elmanuscritozen.com, www.elmanuscritozen.com, localhost

D) Orígenes JavaScript (Google Cloud)
   APIs y servicios → Credenciales → Cliente OAuth "Web client (auto created by Google Service)"
   Orígenes autorizados deben incluir:
   https://elmanuscritozen.com
   https://www.elmanuscritozen.com
   https://el-manuscrit-zen.firebaseapp.com

D2) Restricciones de la apiKey (MUY FRECUENTE si sigue fallando)
   APIs y servicios → Credenciales → "Browser key (auto created by Google Service)"
   Si tiene "Referentes HTTP" restringidos, añade:
   https://elmanuscritozen.com/*
   https://www.elmanuscritozen.com/*
   https://el-manuscrit-zen.firebaseapp.com/*
   Si no estás seguro, pon "Ninguno" (sin restricción) temporalmente para probar.

E) Depurar en el navegador
   F12 → Consola → pulsa "Continuar con Google" → mira la línea "Google sign-in: auth/..."
   (Tras subir la última versión de comments.js verás el código de error en rojo también.)

F) Prueba alternativa
   Registrarse con correo y contraseña. Si eso funciona pero Google no, confirma el paso A.
