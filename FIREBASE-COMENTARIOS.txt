FIREBASE — comentarios (gratis, plan Spark)
==========================================

Solo se usa para: registro de lectores + comentarios.
Las entradas del blog siguen en GitHub (como ahora).

COSTE: 0 € para un blog pequeño (miles de lecturas/mes).

PASO 1 — Crear o abrir proyecto
--------------------------------
https://console.firebase.google.com
Proyecto: el-manuscrit-zen (o crea uno nuevo)

PASO 2 — Authentication
-------------------------
Build → Authentication → Sign-in method
Activa: Correo electrónico/Contraseña
Activa también: Google (recomendado — un clic para comentar)

PASO 3 — Firestore
------------------
Build → Firestore Database → Crear base de datos
Modo: producción → región europe-west (Europa)

Reglas → pegar (sustituye TU_CORREO@gmail.com por tu correo real):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isCommentsAdmin() {
      return request.auth != null
        && request.auth.token.email == 'TU_CORREO@gmail.com';
    }
    match /comments/{postId}/messages/{messageId} {
      allow read: if true;
      allow create: if request.auth != null
        && request.resource.data.uid == request.auth.uid
        && request.resource.data.text is string
        && request.resource.data.text.size() > 0
        && request.resource.data.text.size() <= 500;
      allow update, delete: if request.auth != null
        && (resource.data.uid == request.auth.uid || isCommentsAdmin());
    }
  }
}

MODERAR COMENTARIOS (borrar)
---------------------------
1. En comments-config.js pon tu correo en adminEmail (el mismo de Google/Firebase).
2. En Firestore Reglas usa el mismo correo en isCommentsAdmin().
3. En la web: abre una entrada → Comentarios → Continuar con Google (tu cuenta).
4. Verás "Eliminar" en cada comentario.

Alternativa sin código: Firebase → Firestore → Datos → comments → borrar a mano.

PASO 4 — apiKey en la web
-------------------------
Project settings → General → Your apps → Web (</>)
Copia apiKey → comments-config.js (sustituir TU_API_KEY)

PASO 5 — Subir a GitHub
-----------------------
git add .
git commit -m "Comentarios con Firebase"
git push

Espera 2 min y prueba en www.elmanuscritozen.com
Abre una entrada → Comentarios → Registrarse

-------------------------------------------
